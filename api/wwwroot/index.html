OpenSearch 로그 수집 PoC

  • API가 찍는 표준 JSON 로그(company_id, trace_id 포함)가 Fluent Bit를 거쳐 OpenSearch에 그대로 쌓이는지 확인한다.
  • company_id 기반 DLS(문서 수준 보안)로 회사별 로그가 서로 격리되어 보이는지 실증한다.
  • 구매/삭제 같이 법적 보존이 필요한 기록은 로그가 아니라 MSSQL AuditLogs 테이블로 별도 적재됨을 실증한다.

OpenSearch Dashboards: http://localhost:5601
